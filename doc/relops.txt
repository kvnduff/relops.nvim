*relops.nvim* Remote relative line operations for Neovim

==============================================================================
INTRODUCTION                                                         *relops*

relops.nvim acts on remote relative lines and ranges without moving the cursor
first.
It provides compact normal-mode commands for delete, yank, change, and move.

Repository: https://github.com/kvnduff/relops.nvim
Version: 0.3.0

==============================================================================
SETUP                                                           *relops-setup*

Install with your plugin manager, then call: >lua

  require("relops").setup()
<

Public API: >lua

  require("relops").setup(opts)
  require("relops").delete()
  require("relops").yank()
  require("relops").change()
  require("relops").move()
  require("relops").undo()
  require("relops").redo()
  require("relops").version
<

Default mappings: >text

  dr  delete remote relative line or range
  yr  yank remote relative line or range
  cr  change remote relative line or range
  mr  move remote relative line or range
<

The default mappings avoid Neovim's normal mapping timeout. dr, yr, and cr
enter relops through an operator-pending r, and mr uses an immediate m
dispatcher that forwards non-r keys to native mark setting.

==============================================================================
SYNTAX                                                         *relops-syntax*

In v0.3.0, relops.nvim uses a clearer line/range distinction: >text

  r   remote line
  rr  remote range
<

For the default mappings, dr5j deletes one remote line and drr2j5j deletes a
remote range. Pre-v0.3 repeated-direction forms such as dr15jj, yr15kk,
mr13kk0, and mr2j3j13j are no longer the documented command syntax.

Delete, yank, and change read one remote target after the operation mapping:
>text

  dr15j      delete the single remote line 15j
  yr5k       yank the single remote line 5k
  cr8j       change the single remote line 8j
<

Repeat the r for a remote range: >text

  drr15j18j  delete 15j through 18j
  yrr5k10k   yank 5k through 10k
  yrr5k0     yank 5k through the current cursor line
  crr5k8j    change 5k through 8j
<

Change is linewise: the target line or range is replaced by one empty insert
line. Type one line to replace the whole range with one line, or press Return
in Insert mode to create multiple replacement lines. The linewise replacement
and inserted text undo as one change.

Use 0 for the current cursor line when it is the second endpoint of a range.
Because range order does not matter, put the remote endpoint first. Do not add
j or k after 0.

Move relocates whole lines. It captures the source lines, deletes them so the
gap closes, then inserts them before the destination anchor. The destination is
evaluated against the original visible buffer; when the destination is below the
source, it shifts upward after the source is removed. The buffer line count
stays stable, destination contents are preserved, and destinations inside the
source range are rejected. Registers receive the original moved contents: >text

  mr5j9j     move the single remote line 5j to 9j
  mr5j0      move the single remote line 5j to the current cursor line
<

Repeat the r for a remote source range: >text

  mrr2j5j9j  move 2j..5j so the range starts at 9j
  mrr2j5j0   move 2j..5j to the current cursor line
  mrr5j09k   move 5j..current line so the range starts at 9k
<

Use 0 as the move destination to move a remote line or range to the current
cursor line.

For example, mrr3j4j9j moves 3j..4j to the original 9j anchor. After the source
is removed, original 9j shifts up by two lines, and the moved text is inserted
before that shifted anchor.

==============================================================================
CONFIG                                                         *relops-config*

Defaults: >lua

  require("relops").setup({
    mappings = {
      enabled = true,
      delete = "dr",
      yank = "yr",
      change = "cr",
      move = "mr",
    },
    syntax = {
      current_line = "0",
    },
    yank_highlight = {
      enabled = true,
      group = "IncSearch",
      duration = 180,
    },
    clipboard = {
      unnamed = true,
      yank_register = true,
      delete_register = true,
      system = true,
      selection = true,
    },
    undo = {
      wrap = false,
    },
    notifications = true,
  })
<

Set any mapping to false or an empty string to skip it. Set
`mappings.enabled = false` to skip all operation mappings.

The default current-line token is 0. It can be changed to another single
non-conflicting character: >lua

  require("relops").setup({
    syntax = { current_line = "." },
  })
<

Undo wrapping is opt-in because mapping `u` and `<C-r>` can surprise users: >lua

  require("relops").setup({
    undo = { wrap = true },
  })
<

==============================================================================
TRADEOFFS                                                   *relops-tradeoffs*

relops.nvim reads input after the operation mapping with |getcharstr()|. Native
|showcmd| is therefore not supported for the in-progress range expression.

The default mr timeout fix maps m and preserves native marks for non-r mark
names. If you rely on other normal-mode mappings that start with m, remap move
to a less conflicting key sequence.

Clipboard writes to + and * are protected and silently ignored when unavailable.
<Esc> and <C-c> abort cleanly without mutating the buffer.
